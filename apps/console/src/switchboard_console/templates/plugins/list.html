Plugins

Um plugin é um pacote declarativo que o router recebe pronto: conectores MCP, agentes A2A, bases de conhecimento e playbooks (o jeito de usar tudo isso, no formato Agent Skills). O console valida o pacote, varre o conteúdo e só ativa o que você aprovou e configurou; os roteadores a que você ligar o plugin passam a usá-lo, e o uso é medido por plugin e por versão. Nada de um plugin é executado.

Como chamar

API nativa (devolve rota, decisão, fontes, contratos e spans):

curl -s {{ settings.public_router_url }}/v1/chat -H 'Content-Type: application/json' \
  -d '{"profile": "{{ values.name }}", "message": "sua pergunta"}'

Delegações que passam da espera voltam com HTTP 202, status: "pending" e um run_id. Acompanhe, ou responda quando um agente pedir informação (status: "needs_input"):

curl -s {{ settings.public_router_url }}/v1/runs/RUN_ID            # estado, resposta consolidada, contratos e spans
curl -N {{ settings.public_router_url }}/v1/runs/RUN_ID/events     # o mesmo em tempo real (SSE)
curl -s {{ settings.public_router_url }}/v1/chat -H 'Content-Type: application/json' \
  -d '{"profile": "{{ values.name }}", "run_id": "RUN_ID", "message": "sim, com imóvel em garantia"}'

Qualquer SDK da OpenAI (o roteador aparece como um "modelo"):

from openai import OpenAI

client = OpenAI(base_url="{{ settings.public_router_url }}/v1", api_key="SUA_CHAVE_DO_ROUTER_OU_QUALQUER_TEXTO")
resposta = client.chat.completions.create(
    model="{{ values.name }}",
    messages=[{"role": "user", "content": "sua pergunta"}],
)
print(resposta.choices[0].message.content)

Como chamar

API nativa (devolve rota, agente, fontes e trace):

curl -s {{ settings.public_router_url }}/v1/chat -H 'Content-Type: application/json' \
  -d '{"profile": "{{ values.name }}", "message": "sua pergunta"}'

Qualquer SDK da OpenAI (o roteador aparece como um "modelo"):

from openai import OpenAI

client = OpenAI(base_url="{{ settings.public_router_url }}/v1", api_key="SUA_CHAVE_DO_ROUTER_OU_QUALQUER_TEXTO")
resposta = client.chat.completions.create(
    model="{{ values.name }}",
    messages=[{"role": "user", "content": "sua pergunta"}],
)
print(resposta.choices[0].message.content)
